# Roll a Ball: Estacionamento

Projeto criado na plataforma Unity3D, consistindo em um carro coletando cones brilhantes em um estacionamento noturno, baseado principalmente no conceito original de um jogo Roll a Ball. 

Desenvolvido por Bruna Santana e Lucas Falcão.

Versão unity ultilizada: 6.6(6000.6.2f1)

inputs da movimentação referentes ao script "playercontroller" foram alterados de forma a proporcionar um movimento fluído ao veículo(player). Adicionais como o mapa, script de texto inicial(aviso), iluminação e outros objetos, foram criados inteiramente dentro do projeto da Unity.
