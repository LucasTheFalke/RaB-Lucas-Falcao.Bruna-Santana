# Roll a Ball: Estacionamento

Projeto em Unity de um carro coletando cones brilhantes em um estacionamento noturno, baseado no conceito original de um jogo roll a ball. Desenvolvido por Bruna Santana e Lucas Falcão.

Versão unity ultilizada: 6.6(6000.6.2f1)

inputs da movimentação referentes ao script "playercontroller" foram alterados, de forma a impor um movimento fluído ao veículo(player). Adicionais como mapa, iluminação e outros objetos foram criados inteiramente dentro do projeto da unity. O link referente ao modelo da asset store será disponibilizado abaixo.
